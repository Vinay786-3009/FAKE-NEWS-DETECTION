# Fake News Detection & News Credibility Analyzer

An NLP and machine learning application that analyzes linguistic patterns in
news content and provides an **ML-based classification** (REAL /
POTENTIALLY FAKE) with a credibility/risk indicator and explainable results —
all in an interactive Streamlit dashboard.

> ⚠️ **Disclaimer:** This system does **not** verify facts against
> authoritative sources. It only predicts patterns learned from its training
> dataset. A prediction of "REAL" does not mean the article is factually
> verified, and "POTENTIALLY FAKE" does not prove an article is false. Verify
> important claims with reliable primary sources and professional
> fact-checking organizations.

## Overview

The app takes a news headline and/or article as input and runs it through a
complete NLP + ML pipeline:

1. **Preprocessing** – lowercasing, HTML/URL removal, punctuation removal,
   tokenization, stopword removal and lemmatization.
2. **Feature engineering** – TF-IDF vectors (word 1–2 grams, sublinear TF).
3. **Classification** – Logistic Regression and a calibrated LinearSVC are
   trained and compared; the best model by F1 is deployed.
4. **Explainability** – the words that pushed the prediction are shown per
   article (computed from model coefficients, never hard-coded).
5. **NLP insights** – text statistics, sentiment, keywords and
   sensational-language indicators.

## Problem Statement

Misinformation spreads quickly online, and readers lack accessible tools to
understand *why* a piece of content looks suspicious. This project builds an
interpretable ML classifier that highlights the linguistic patterns
associated with the fake-news class in its training data.

## Objectives

- Classify news text as REAL or POTENTIALLY FAKE with a confidence score
- Provide an ML-confidence-based credibility/risk indicator (0–100)
- Explain every prediction with feature-level evidence
- Offer rich NLP analytics: statistics, sentiment, keywords, sensational
  language signals
- Support batch CSV analysis with downloadable results
- Handle empty, short, duplicate and malformed input gracefully

## Technology Stack

- **Python 3** · Pandas · NumPy
- **scikit-learn** – TF-IDF, Logistic Regression, LinearSVC, calibration,
  evaluation
- **NLTK** – tokenization, stopwords, WordNet lemmatization (with graceful
  fallback if corpora are missing)
- **Plotly / Matplotlib** – interactive and static charts
- **Streamlit** – web application (no separate backend needed)
- **joblib** – model persistence

## NLP Pipeline

```
raw text → lowercase → remove HTML → remove URLs → unicode normalize
        → remove punctuation → collapse spaces → tokenize
        → remove stopwords → lemmatize → clean text
```

`clean_text()` (in `src/preprocessing.py`) never crashes on `None`, NaN,
non-string input, or empty strings.

## Machine Learning Approach

- **Features:** TF-IDF (`max_features=20000`, `ngram_range=(1,2)`,
  `min_df=2`, `max_df=0.9`, `sublinear_tf=True`)
- **Models:** Logistic Regression and LinearSVC (calibrated with
  `CalibratedClassifierCV` so it can output confidence scores)
- **Split:** stratified 80/20 train/test with `random_state=42`
- **Selection:** the model with the highest **F1** on the test split is saved
- **Metrics:** accuracy, precision, recall, F1 and a confusion matrix — all
  computed from the actual evaluation data

Current trained metrics (computed, synthetic dataset): see
`models/metrics.json` or the *Model Performance* page in the app.

## Dataset

`data/news_dataset.csv` is a **synthetic demonstration dataset** generated by
`src/generate_dataset.py` (1,200 articles, balanced REAL/FAKE, with
`title`, `text`, `subject`, `date`, `label` columns). REAL-class articles use
neutral, source-attributed reporting templates; FAKE-class articles use the
sensational linguistic patterns typical of fake-news corpora. **No real-world
news claims are fabricated and labelled as factual.**

To use a real dataset (e.g. the Kaggle *Fake and Real News Dataset* —
Fake.csv + True.csv), place it at `data/news_dataset.csv` with a `text` and
`label` column (labels normalized automatically), then retrain.

## Model Evaluation

Run `python src/train_model.py` to (re)train. It prints accuracy, precision,
recall and F1 for both models, saves the best one and writes
`models/metrics.json`. The app's *Model Performance* page visualizes the
comparison table, confusion matrix and actual-vs-predicted counts.

## Free Cloud Deployment (Streamlit Community Cloud)

2. Click **"New app"**.
3. Select your repository: `Vinay786-3009/FAKE-NEWS-DETECTION`.
4. Set the Main file path: `app.py`.
5. Click **"Deploy!"**.

## Limitations

- No fact-checking against external sources — pattern classification only
- Trained on a synthetic corpus; metrics do not transfer to real data
- English only
- Lexicon-based sentiment is simple by design
- The credibility score is a model-confidence indicator, not an official
  rating
